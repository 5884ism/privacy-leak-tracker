更新ルール

毎日1回、主要ニュース検索・指定RSSから候補記事を取得し、重複を除去して data/incidents.json に反映します。自動取得した案件は 「報道検知・要確認」 として表示できます。公式発表などで確認後、status を confirmed または possible に変更してください。

GitHub ActionsでJSON更新→GitHubへ自動コミット→Cloudflare Pages / GitHub Pagesが自動公開、という構成を想定しています。

※ 本サイトは注意喚起・情報整理を目的とした非公式データベースです。個別案件の正確な範囲・対象者・対応方法は企業等の公式発表を確認してください。
